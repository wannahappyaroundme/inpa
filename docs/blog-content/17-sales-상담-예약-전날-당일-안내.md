# 상담 예약 전날과 당일 보내는 안내 문장

<!-- blog-body -->

예약 안내는 약속을 다시 설득하는 문자가 아니라, 고객이 시간과 참여 방법을 확인하고 필요하면 쉽게 바꾸게 하는 안내입니다. 전날에는 시간, 장소나 접속 주소, 알고 있는 경우의 상담 시간, 준비물, 변경 방법을 한 번에 적으세요. 당일에는 새 설명을 늘리지 말고 핵심만 짧게 확인합니다.

보내기 전에는 예약 날짜와 시간대, 대면 장소 또는 온라인 주소, 예상 시간을 실제로 정했는지, 꼭 필요한 준비물이 있는지, 변경 요청을 받을 방법을 확인합니다. 정하지 않은 상담 시간을 임의로 약속하지 말고 “약 40분”처럼 알고 있는 경우에만 씁니다.

## 전날 문장은 다섯 부분이면 충분합니다

1. 보낸 사람과 예약한 상담을 밝힙니다.
2. 날짜와 시간을 요일·오전·오후까지 적습니다.
3. 장소나 접속 주소를 하나만 분명히 둡니다.
4. 예상 시간과 준비물은 정해진 내용만 적습니다.
5. 변경이나 취소를 요청할 쉬운 방법을 알립니다.

> 안녕하세요, 이 설계사입니다. 내일 8월 6일 목요일 오후 7시에 온라인 상담으로 뵙기로 한 일정 확인드립니다. 상담은 약 40분으로 잡아두었고, 함께 보기로 한 증권 사본만 준비해주시면 됩니다. 시간 변경이나 취소가 필요하시면 이 문자에 편하게 답해주세요.

대면 상담이라면 건물 이름만 적지 말고 고객이 찾을 수 있는 층이나 만나는 지점을 덧붙입니다. 주차나 출입 등록처럼 꼭 알아야 할 내용이 있을 때만 짧게 포함합니다.

## 당일에는 무엇만 남길까요?

당일 안내는 시간과 들어오는 방법, 변경 경로만 다시 보여주면 됩니다.

> 안녕하세요, 오늘 오후 7시 상담 일정 확인드립니다. 온라인 상담 주소는 아래와 같습니다. 접속이 어렵거나 시간을 바꾸고 싶으시면 이 문자에 답해주세요. [접속 주소]

고객이 이미 변경을 요청했다면 예전 일정 안내를 다시 보내지 않습니다. 취소 답을 받았다면 이유를 캐묻기보다 확인 문장을 보내고 일정을 정리합니다. “확인했습니다. 말씀하신 오늘 일정은 정리해둘게요. 다시 시간을 잡고 싶으실 때 편하게 알려주세요” 정도면 충분합니다.

가상의 예를 들어볼게요. 최 설계사는 고객과 사무실 상담을 잡았지만 예상 시간은 아직 정하지 않았습니다. 전날 문자에는 목요일 오후 3시, 건물 2층 안내 데스크, 증권 사본, 답장으로 변경하는 방법만 적었습니다. 상담 시간을 추측해 넣지 않았고, 당일 고객이 30분 늦추고 싶다고 하자 가능한지 확인한 뒤 새 시간만 다시 보냈습니다.

예약 전 첫 안내 문장은 [부재중 뒤 보내는 상담 안내 문자](/blog/상담-예약률-높이는-문자와-화법)에서 확인할 수 있습니다. 상담이 끝난 다음 약속은 [상담 후 기록과 다음 연락 정하기](/blog/보험-상담-후-기록-다음-연락)에 정리했습니다.

## 흔히 놓치는 점

- 날짜는 적고 요일이나 오전·오후를 빼는 것
- 대면 장소와 온라인 주소를 한 문자에 함께 넣는 것
- 정하지 않은 상담 시간과 준비물을 확정해 알리는 것
- 변경과 취소 방법을 숨기거나 전화 한 가지로만 제한하는 것
- 예약 확인 문자에 새로운 상품 안내를 길게 붙이는 것

## 보내기 전 저장용 체크리스트

- [ ] 날짜, 요일, 오전·오후와 시간을 확인했다
- [ ] 장소 또는 접속 주소가 하나로 분명하다
- [ ] 예상 시간은 실제로 정한 경우에만 넣었다
- [ ] 준비물은 이번 상담에 필요한 것만 적었다
- [ ] 변경이나 취소를 요청할 방법을 적었다
- [ ] 이전 일정이 바뀌었다면 최신 시간만 남겼다

인파 예약에서는 설계사가 일하는 시간을 열어 두고 고객이 가능한 시간을 직접 고를 수 있습니다. 예약 요청을 확인한 뒤 수락하거나 다른 일정을 상의할 수 있어, 안내 문장에 최신 시간과 예약 링크를 정확히 넣기 좋습니다.
