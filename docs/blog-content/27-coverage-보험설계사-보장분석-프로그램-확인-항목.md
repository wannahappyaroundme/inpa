# 보험설계사 보장분석 프로그램, 자동 정리 뒤 확인할 6가지

<!-- blog-body -->

보험설계사 보장분석 프로그램의 자동 정리는 완성된 판단표가 아니라 원문을 빠르게 대조하기 위한 초안입니다. 계약의 대상과 상태, 보험료, 기간, 담보 연결, 금액이 증권과 맞는지 여섯 번 확인한 뒤 고객 설명에 사용하세요. 화면이 매끄러워 보여도 읽히지 않은 값과 잘못 연결된 한 줄이 전체 합계를 바꿀 수 있습니다.

확인 순서는 “어느 상품이 낫다”는 결론을 만드는 과정이 아닙니다. 고객이 가진 계약을 사실대로 정리하고, 원문에서 더 볼 질문을 남기는 과정입니다.

## 원문과 자동 정리 화면을 나란히 엽니다

증권 파일과 정리 화면을 번갈아 기억으로 비교하지 마세요. 같은 화면에 나란히 놓거나 한 항목씩 체크해 위치를 표시합니다. 원문 페이지나 표의 위치를 메모해두면 상담 중 다시 확인하기 쉽습니다.

| 원문 | 자동 정리 | 설계사 재확인 |
|---|---|---|
| 계약자·피보험자와 계약 상태 | 고객·보험 기본 정보 | 다른 가족 계약이 섞이지 않았고 현재 상태가 맞는가 |
| 월 보험료와 보험료 구성 | 보험료 합계와 구분 | 갱신형·비갱신형·적립 부분이 원문과 같은가 |
| 납입기간·보험기간·갱신 주기 | 기간 정보 | 주계약과 특약의 서로 다른 기간이 유지됐는가 |
| 증권의 원래 담보명 | 공통 보장 항목 | 지급 사유가 다른 담보가 같은 항목에 묶이지 않았는가 |
| 담보별 가입금액 | 보유 금액 합계 | 단위와 금액이 맞고 미상 값을 숫자로 채우지 않았는가 |
| 지급 조건·횟수·제외 내용 | 짧은 항목명 또는 메모 | 고객 설명 전에 약관에서 더 확인할 질문을 남겼는가 |

## 1~2. 대상과 보험료부터 맞춥니다

첫째, 계약자와 피보험자를 구분하고 어떤 고객의 보장인지 확인합니다. 가족 증권 여러 장을 한꺼번에 올렸다면 다른 사람의 계약이 섞이지 않았는지 먼저 봅니다. 계약 이름보다 정상 유지, 납입 완료, 효력 정지처럼 현재 상태를 확인해야 보유 금액에 넣을 범위가 분명해집니다.

둘째, 월 보험료 합계와 구성을 대조합니다. 한 계약 안에 갱신형 담보, 비갱신형 담보, 적립 부분이 섞일 수 있으므로 전체에 한 가지 이름을 붙이지 않습니다. 원문에서 항목별 금액을 알 수 없다면 합계만 확인하고 세부 칸은 미상으로 남기는 편이 정확합니다.

## 3~4. 기간과 담보 연결을 따로 봅니다

셋째, 납입기간과 보험기간을 나눠 봅니다. “20년 납”과 “몇 세 만기”는 같은 값이 아닙니다. 주계약과 특약의 만기, 갱신 주기와 종료 나이가 다르면 자동 정리 화면에서도 각각 유지되는지 확인하세요.

넷째, 원래 담보명과 공통 보장 항목의 연결을 확인합니다. 비슷한 이름이라도 진단, 수술, 입원, 치료처럼 지급 계기가 다를 수 있습니다. 연결되지 않은 담보는 보장이 없는 것으로 처리하지 말고 직접 확인할 줄로 남깁니다. 이름이 낯선 항목일수록 원문과 약관 위치를 함께 적어두는 편이 좋습니다.

## 5~6. 금액과 빠진 조건을 확인합니다

다섯째, 담보별 가입금액의 단위와 합계를 확인합니다. `만원`과 `원`, 월 금액과 연 금액을 섞지 않고, 숫자를 읽지 못한 항목에 임의의 0을 넣지 않습니다. 여러 담보가 같은 공통 항목에 연결됐다면 개별 내역을 펼쳐 중복이나 누락을 봅니다.

여섯째, 자동 정리 화면에 모두 담기기 어려운 지급 조건을 질문으로 남깁니다. 진단 확정 방법, 지급 횟수, 대기·감액 조건, 보장하지 않는 사항은 해당 증권과 약관에서 확인합니다. 짧은 담보명과 금액표만으로 지급 여부를 단정하지 않습니다.

## 색이 보이면 기준부터 확인합니다

보장 상태를 넉넉·적정·부족으로 표시하는 화면에서는 어떤 기준이 적용됐는지 먼저 확인하세요. 인파는 설계사가 직접 확인해 저장한 기준이 있을 때만 상태를 표시하고, 기준이 없으면 등록된 보장금액만 보여줍니다. 색은 원문 확인을 대신하지 않으며 상품이나 계약 변경 방향을 정해주지 않습니다.

마지막으로 화면의 각 숫자에서 원래 증권 줄로 돌아갈 수 있는지 시험해보세요. 출처를 다시 찾기 어려운 합계는 상담 중 질문을 받았을 때 근거를 설명하기 어렵습니다.

## 상담 전 여섯 칸을 한 번 더 봅니다

- [ ] 계약자·피보험자와 현재 계약 상태
- [ ] 월 보험료와 갱신형·비갱신형·적립 구분
- [ ] 납입기간·보험기간·갱신 주기
- [ ] 원래 담보명과 공통 항목 연결
- [ ] 담보별 금액·단위·미상 값
- [ ] 약관에서 더 확인할 지급 조건

**오늘 할 일: 증권 한 장과 [인파 보장분석 흐름](https://www.inpa.kr/solutions/policy-analysis)을 나란히 열고, 여섯 칸 가운데 원문으로 되돌아가지 못하는 항목부터 표시해보세요.**
