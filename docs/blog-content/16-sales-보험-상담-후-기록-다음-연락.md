# 보험 상담 뒤 기록할 5가지와 다음 연락 정하는 법

<!-- blog-body -->

보험 상담 뒤 기록은 대화를 길게 받아쓰는 일이 아닙니다. 고객이 확인하려던 목표, 답이 남은 질문, 서로 보내기로 한 문서, 다음 행동의 담당자와 날짜, 고객이 편하다고 한 연락 방법만 짧게 남기세요. 다음 연락에서 약속을 바로 이어갈 수 있으면 충분합니다.

주민등록번호, 진단명과 치료 이력의 원문, 가족의 상세 사정처럼 다음 행동에 필요하지 않은 내용은 자유 메모에 옮기지 않습니다. 꼭 확인해야 하는 민감한 내용은 회사가 정한 공식 절차와 보관 위치를 따르고, 일반 상담 메모에는 “회사 절차로 추가 확인”처럼 할 일만 남깁니다.

## 다섯 칸에는 무엇을 적을까요?

1. **고객 목표:** 고객이 자신의 말로 확인하고 싶다고 한 주제 한두 가지
2. **남은 질문:** 설계사가 원문이나 회사에 확인해 답할 내용
3. **약속한 문서:** 누가 어떤 자료를 보내기로 했는지
4. **다음 행동:** 담당자와 날짜가 들어간 한 문장
5. **연락 방법:** 전화, 문자 등 고객이 고른 방법과 편한 시간

“추가 안내 예정”처럼 주체와 날짜가 없는 메모는 다음 행동이 아닙니다. “이 설계사, 8월 12일까지 갱신 주기 확인 후 문자”처럼 누가 언제 무엇을 할지가 보여야 합니다.

## 짧은 후속 메모와 자료철은 어떻게 다를까요?

후속 메모는 다음 대화를 시작하기 위한 길잡이입니다. 고객의 목표와 약속만 요약하고, 증권 원문과 공식 서류는 정해진 위치에서 따로 관리합니다. 모든 대화와 문서를 한 자유 입력 칸에 쌓으면 필요한 약속을 찾기 어렵고, 보관할 이유가 없는 민감한 내용까지 오래 남기기 쉽습니다.

| 후속 메모에 남길 것 | 자유 메모에 옮기지 않을 것 |
|---|---|
| “보장 기간을 먼저 확인하고 싶음” | 진단서나 치료 기록의 원문 |
| “설계사, 금요일까지 약관 범위 확인” | 주민등록번호와 계좌 정보 |
| “고객, 다음 주 증권 한 면 추가 전달” | 가족의 상세 병력과 생활사 |
| “문자 선호, 평일 저녁” | 상담과 관계없는 대화 전체 |

가상의 상담을 보겠습니다. 박 설계사는 고객이 “갱신되는 특약과 보장 종료 시점을 알고 싶다”고 한 목표를 적었습니다. 답이 남은 담보 한 건은 원문 확인으로 표시하고, 고객은 화요일에 빠진 증권 면을 보내기로 했습니다. 박 설계사는 수요일 저녁 문자로 답하기로 날짜를 정했습니다. 병력 대화는 메모에 옮기지 않았습니다.

첫 연락과 멈춤 기준은 [부재중 뒤 보내는 상담 안내 문자](/blog/상담-예약률-높이는-문자와-화법)에서 확인하세요. 고객 기록의 기본 칸을 잡으려면 [보험설계사 고객관리표에 필요한 일곱 칸](/blog/보험설계사-고객관리표-필수-항목)이 이어집니다.

## 흔히 놓치는 점

- 상담 내용을 처음부터 끝까지 그대로 붙여 넣는 것
- 고객 목표를 설계사의 결론으로 바꾸어 적는 것
- “추후 연락”처럼 담당자와 날짜를 빼는 것
- 약속한 문서가 고객 몫인지 설계사 몫인지 구분하지 않는 것
- 고객이 원한 연락 방법과 멈춰 달라는 뜻을 남기지 않는 것

## 상담 직후 저장용 체크리스트

- [ ] 고객이 말한 목표를 한두 문장으로 적었다
- [ ] 답이 남은 질문과 확인 경로를 표시했다
- [ ] 서로 보내기로 한 문서와 담당자를 나눴다
- [ ] 다음 행동에 담당자와 날짜를 넣었다
- [ ] 고객이 고른 연락 방법과 시간을 적었다
- [ ] 자유 메모에서 불필요한 민감정보를 뺐다

인파의 고객 상세에서는 상담 메모를 고객별로 나누어 남기고, 영업 단계와 최근 연락 기록을 함께 관리할 수 있습니다. 대화 전체보다 다음 약속을 찾기 쉬운 기록을 만들고 싶은 설계사에게 맞습니다.
