# 인파 노트 릴리스 원고 (20편)

브랜드 보이스 가이드([00-brand-voice-guide.md](00-brand-voice-guide.md)) 기준으로 정리한 기존 13편과 신규 실무 글 7편입니다. 릴리스 구성은 **공개 글 17편 + 법무 확인 전 비공개 안심 가이드 3편**입니다. 저장소 원고는 검증된 릴리스 명령으로 반영하고, 운영에서 직접 고친 내용은 적용 전에 백업합니다.

## 특징
- **쉬운 말 원칙**: '중립·시각화·정규화·인바운드·리드' 같은 내부/마케팅 용어를 빼고, 설계사·가입자가 실제 쓰는 말로 씀(PM 지시).
- 계약 변경 3편(07·08·10)은 실제 법무 검토 기록 전까지 비공개로 유지합니다.
- 공개 글은 본문 정직성 문구를 반복하지 않고, 상세 화면의 공식 고지 한 곳을 사용합니다.
- 모든 사실 출처는 원고 메타데이터에 직접 URL과 `checked_at`을 남깁니다.

## 운영 메모
- 적용: Render 시작 과정에서 검증된 콘텐츠 릴리스 명령을 실행합니다. 같은 버전과 내용은 다시 쓰지 않으며, 적용 전·후 snapshot은 운영 DB에 함께 보존합니다.
- 복원: 운영에서 이후 편집이 없을 때 `python manage.py refresh_blog_content --restore-from-marker --confirm-version 2026-08-blog-enrichment-v1`로 DB snapshot을 복원합니다.
- 07·08·10은 `review_gate: "legal"`, `legal_review: null`, `is_published: false`를 유지합니다.
- 법률 검토 기록은 담당자, 자격, 서버 확인 시각, 내부 근거를 모두 저장하며 제목·본문·요약·대표 이미지·분류·태그·검색 정보의 현재 버전과 결합됩니다. 글 저장과 검토 확인은 별도 버튼으로 진행합니다. 저장 뒤 다른 탭에서 글이 바뀌면 검토 확인이 멈추며, 검토 뒤 해당 내용을 고치면 다시 비공개로 저장하고 새 검토를 받아야 합니다.
- 배포 원고는 법률 검토 기록과 법률 글 공개 상태를 받을 수 없습니다. 실제 검토와 공개는 관리자 화면의 별도 확인 단계에서만 진행합니다.
- 공개 화면에는 검토 담당자, 자격, 확인일만 표시하며 내부 근거는 공개하지 않습니다.
