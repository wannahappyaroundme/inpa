# 보험 계약 변경 비교·고지 항목 읽는 법

<!-- blog-body -->

보험업법 제97조의 관련 규정은 기존 계약과 보장 내용 등이 비슷한 새 계약을 대상으로 합니다. 기존 계약 소멸과 새 계약 청약이 서로 6개월 이내인 상황에서 중요한 사항을 비교해 알리지 않은 행위를 같은 조 제3항 제2호가 규정합니다. 이때 쓰는 공식 서류와 설계사가 상담 준비에 쓰는 정리표는 역할이 다릅니다.

공식 서류는 해당 보험회사나 모집 채널의 최신 양식과 절차에 따라 작성·교부하고, 고객 확인도 그 절차 안에서 받아야 합니다. 인파의 비교 화면이나 설계사가 따로 만든 표는 상담 내용을 이해하기 쉽게 정리할 수 있지만, 공식 서류를 발행하거나 인증하거나 대신하지 않습니다.

## 비교·고지 항목에는 무엇이 들어갈까요?

보험업법 시행령 제44조는 위 6개월 이내 상황에서 비교해 알릴 중요한 사항을 정합니다. 그 밖의 일반 비교에 아래 표를 쓸 때는 실무 확인표이며, 모든 상담에 같은 법정 절차가 적용된다는 뜻은 아닙니다.

![법정 비교·고지 항목과 상담용 정리표의 관계를 보여주는 그림](/blog-assets/비교안내서-한눈에-보는-비교표/comparison-document-map.webp)

| 항목 | 문서에서 확인할 내용 | 읽을 때 주의할 점 |
|---|---|---|
| 보험료 | 현재·새 계약의 납입액 | 납입주기와 갱신 여부를 함께 본다 |
| 보험기간 | 보장이 이어지는 기간 | 주계약과 특약 만기가 다른지 본다 |
| 납입주기·기간 | 월납·연납, 납입 종료 시점 | 총 납입기간과 남은 기간을 나눈다 |
| 보험가입금액·주요 보장 내용 | 가입금액과 보장 내용 | 이름보다 약관의 지급 조건을 본다 |
| 납입보험료 대비 환급금액의 비율 | 계약 문서의 비율 | 기준 시점과 계산 조건을 확인한다 |
| 보험금액 | 계약 문서의 보험금액 | 환급금액의 비율과 별도로 확인한다 |
| 예정이율 | 계약에 적용된 수치 | 어느 금액 계산에 쓰이는지 확인한다 |
| 보험목적 | 보장 대상 | 피보험자와 대상 위험을 맞춘다 |
| 보험회사의 면책사유·면책사항 | 계약 문서의 면책 내용 | 한쪽에만 있는 면책 내용을 찾는다 |

표의 빈칸을 임의로 채우지 않는 것도 중요합니다. 숫자나 조건을 찾지 못했다면 미상으로 남기고, 보험회사 고객센터, 담당 모집 채널, 해당 계약의 증권·약관처럼 공식 경로에서 확인한 뒤 기록합니다.

## 상담용 화면과 공식 서류를 어떻게 나눌까요?

상담용 화면은 여러 장의 증권에서 같은 항목을 찾아 차이를 발견하는 데 씁니다. 공식 서류는 법과 회사 절차에 따라 비교·고지 사실을 남기는 데 씁니다. 둘을 연결할 때는 다음 순서가 분명합니다.

1. 증권과 약관에서 원문 값을 찾는다.
2. 상담용 화면에 증권 A·B로 정리해 누락과 차이를 확인한다.
3. 해당 보험회사나 모집 채널의 최신 공식 양식에 값을 옮겨 대조한다.
4. 고객에게 항목별 차이를 설명하고 회사 절차에 따라 확인을 받는다.
5. 공식 서류의 교부·보관 방법도 소속 회사 기준을 따른다.

![원문 확인부터 공식 양식 대조까지 이어지는 다섯 단계](/blog-assets/비교안내서-한눈에-보는-비교표/official-verification-flow.webp)

## 흔히 놓치는 점

- 상담용 정리표를 보험회사가 발행한 공식 서류처럼 부르는 것
- 양식의 개정일을 확인하지 않고 저장해둔 옛 서류를 다시 쓰는 것
- 보험가입금액, 보험금액, 환급금액의 비율을 같은 값으로 처리하는 것
- 값의 기준일과 확인한 증권·약관 위치를 남기지 않는 것

증권의 기본 항목을 찾는 순서는 [보험 증권에서 먼저 확인할 다섯 가지](/blog/보험-증권-보는-법-3분-체크리스트)에 정리했습니다. 납입 방식과 보험료 흐름을 구분하려면 [갱신형과 비갱신형의 차이](/blog/갱신형-비갱신형-차이)를 함께 확인하세요.

## 공식 서류를 확인할 때 남길 기록

- 사용한 양식의 이름과 개정일
- 기존 계약과 새 계약을 확인한 기준일
- 값을 확인한 증권·약관의 쪽이나 항목
- 미상 값을 확인한 보험회사 또는 모집 채널
- 고객에게 설명하고 교부한 회사 절차상의 기록

인파의 여러 증권 비교는 보험료와 보장 내용을 증권 A·B로 나란히 정리해 확인할 차이를 찾도록 돕습니다. 공식 비교·고지 서류는 보험회사와 소속 모집 채널의 최신 양식과 절차로 별도 확인해야 합니다.
