# 신입 보험설계사, 지인 소개 다음에 할 일

<!-- blog-body -->

지인이 누군가를 소개해줬다면 바로 상담 일정을 잡기보다, 소개받은 분이 연락을 받을지와 다음 행동을 직접 고르게 해야 합니다. 소개자는 연결까지만 맡고, 상담 여부와 내용은 당사자와 설계사 사이에 남기는 흐름이 기본입니다.

처음 받을 정보도 이름, 연락 가능한 방법, 연락해도 되는 시간처럼 연결에 필요한 범위로 줄이세요. 주민등록번호, 병력, 증권 사진은 상담 의사가 확인된 뒤에도 목적과 전달 방법을 먼저 설명하고 받아야 합니다.

## 소개 뒤 흐름은 어떻게 잡을까요?

소개자는 설계사 소개 카드나 연락처를 전달합니다. 고객은 카드를 보고 상담 신청, 예약, 나중에 보기 중에서 원하는 행동을 고릅니다. 설계사는 고객이 직접 남긴 연락 방법으로만 답하고, 소개자에게 상담 여부나 결과를 되돌려 알리지 않습니다.

![소개를 받은 고객이 직접 다음 행동을 고르는 세 단계 흐름](/blog-assets/신입-보험설계사-지인-영업-다음-할-일/referral-flow.webp)

| 단계 | 누가 하나요 | 남기는 정보 |
|---|---|---|
| 1. 소개 | 소개자 | 설계사 소개 카드나 공개 연락처 전달 |
| 2. 선택 | 고객 | 상담 신청, 예약, 나중에 보기 중 선택 |
| 3. 응대 | 설계사 | 고객이 고른 연락 방법과 시간에 맞춰 답변 |

이 구조의 장점은 소개자가 고객의 민감한 사정을 대신 설명하지 않아도 된다는 점입니다. 고객도 먼저 연락받는 이유를 알고, 진행 속도를 스스로 정할 수 있습니다.

## 첫 연락에는 무엇을 물어보면 될까요?

첫 연락에서 필요한 것은 많지 않습니다.

- 어떻게 불러드리면 되는지
- 답을 받을 전화번호나 문자 방법
- 연락이 편한 요일과 시간
- 지금 가장 궁금한 주제 한 가지

보험 가입 내역, 병명, 주민등록번호, 가족의 상세 정보는 첫 연락에 넣지 않습니다. 증권이 필요한 상담이라면 왜 필요한지, 어디로 보내는지, 무엇을 가려도 되는지부터 설명한 뒤 고객이 선택하게 합니다.

가상의 예를 들어볼게요. 박 설계사의 기존 고객이 동료에게 소개 카드를 보냈습니다. 동료는 카드에서 "다음 주에 통화"를 골라 이름과 연락 가능 시간만 남겼습니다. 박 설계사는 소개자에게 "연락이 닿았다"는 확인도 보내지 않고, 동료와 정한 시간에 직접 대화를 시작했습니다. 소개자의 호의와 고객의 상담 내용이 섞이지 않는 흐름입니다.

## 소개자에게 어디까지 말해도 될까요?

감사 인사는 소개를 받은 사실까지만 두는 편이 분명합니다. 고객이 상담했는지, 어떤 보험을 갖고 있는지, 계약을 진행했는지 같은 내용은 고객이 따로 요청하지 않는 한 소개자와 공유하지 않습니다. 소개자가 물어보면 "상담 내용은 당사자와만 확인하고 있어요"라고 짧게 답하면 됩니다.

후속 연락 문장이 막힐 때는 [부재중 뒤 보내는 상담 안내 문자](/blog/상담-예약률-높이는-문자와-화법)를 함께 보세요. 고객 정보를 어느 정도만 남길지 고민된다면 [고객관리표에 필요한 일곱 칸](/blog/보험설계사-고객관리표-필수-항목)이 이어집니다.

## 흔히 놓치는 점

- 소개자가 대신 보낸 병력이나 증권을 바로 저장하는 것
- 고객의 의사를 확인하기 전에 여러 차례 연락하는 것
- 소개자에게 상담 여부나 계약 결과를 알려주는 것
- 첫 대화부터 가족 정보와 상세 병력을 한꺼번에 묻는 것

## 첫 달 저장용 체크리스트

- [ ] 1주차: 내 소개 문장과 소개 카드를 실제 화면에서 확인한다
- [ ] 2주차: 고객이 직접 선택할 수 있는 연락 방법을 정리한다
- [ ] 3주차: 첫 연락에 받는 정보를 네 가지 이내로 줄인다
- [ ] 4주차: 소개자에게 결과를 전하지 않는 응대 문장을 메모한다

인파의 내 소개 카드는 고객이 설계사 정보를 확인한 뒤 직접 상담을 신청하도록 돕고, 신청된 고객은 단계별 화면에서 다음 행동과 함께 관리할 수 있습니다. 소개 뒤 선택권과 기록을 한 흐름으로 챙기고 싶은 설계사에게 맞습니다.
