# 보험 직업급수 1·2·3급, 회사마다 달라질 수 있는 이유와 확인 순서

<!-- blog-body -->

보험 직업급수 1·2·3급은 직업명만 보고 모든 회사에 똑같이 붙이는 공통 자격표가 아닙니다. 회사와 상품의 인수 기준, 실제 맡은 일, 근무 장소, 차량이나 기계 사용 여부, 여러 직무의 비중과 확인 날짜에 따라 분류 결과가 달라질 수 있습니다.

따라서 검색 결과 한 건은 후보를 찾는 출발점으로 쓰고, 가입하려는 회사와 상품에서 최종 분류를 확인해야 합니다. “사무직은 무조건 1급”처럼 직함만으로 등급을 약속하지 않습니다.

## 먼저 어떤 정보를 물어야 할까요?

회사에 직업명을 전달하기 전에 다음 내용을 고객이 설명할 수 있는 범위에서 정리합니다.

- 회사에서 쓰는 직함과 실제 하는 일
- 사무실, 현장, 이동 근무 등 주된 근무 환경
- 운전이 업무인지 출퇴근인지, 사용하는 차량 종류
- 절단·용접·굴착처럼 기계나 장비를 직접 다루는지
- 관리와 현장 업무를 함께 한다면 각각의 비중
- 현재 일을 시작했거나 업무가 바뀐 날짜

직함이 같아도 “현장에 나가는 관리자”와 “사무실에서 관리만 하는 관리자”는 회사에 전달할 실제 업무가 다릅니다. 큰 직업명 아래 세부 항목이 여러 개 나오면 이름이 익숙한 것을 고르기보다 설명과 업무를 대조해야 합니다.

## 다섯 단계로 확인하세요

![실제 업무 확인부터 회사 분류와 변경 기록까지 이어지는 직업급수 확인 흐름](/blog-assets/보험-직업급수-확인-순서/job-grade-flow.webp)

1. **실제 업무를 적습니다.** 직함, 작업 내용, 장소, 차량·기계 사용과 여러 직무의 비중을 한 줄씩 씁니다.
2. **회사와 상품을 정해 검색합니다.** 같은 고객도 가입하려는 계약이 달라지면 해당 회사의 현재 기준을 다시 찾습니다.
3. **가까운 항목을 나란히 봅니다.** 이름이 비슷한 두세 항목의 설명을 비교하고, 어느 부분이 고객 업무와 같고 다른지 표시합니다.
4. **인수 담당 경로로 확인합니다.** 애매한 항목과 여러 직무는 설계사가 임의로 고르지 않고 회사의 공식 확인을 받습니다.
5. **근거와 날짜를 남깁니다.** 확인한 회사·상품, 직업 항목, 답을 받은 날짜를 적고 이후 업무가 바뀌면 다시 확인합니다.

손해보험협회 소비자포털도 여러 직무의 상해급수는 보험회사의 인수심사기준 등에 따라 정해지는 사항이라고 설명합니다. 최근 판례에서도 직업이나 직무 변경 사실을 보험회사에 알린 내용과 처리 과정을 계약별 사정과 함께 판단했습니다. 실무에서는 법률 결론을 미리 내리기보다 변경 사실을 발견했을 때 해당 회사의 현재 절차로 확인하고 기록하는 편이 분명합니다.

가상의 예를 보겠습니다. “시설관리 직원”인 고객이 평소 건물 점검을 하고, 주 2회 사다리 작업과 소형 장비 운반을 하며 업무용 차량도 운전한다고 말했습니다. 설계사는 시설관리라는 이름만 검색해 등급을 정하지 않았습니다. 현장 점검, 장비 사용, 운전이 포함된 가까운 항목을 비교해 회사에 전달하고, 확인한 항목과 날짜를 기록했습니다.

가입 전에 직업과 함께 확인할 질문은 [보험 가입 전 다섯 가지 확인사항](/blog/보험-가입-전-확인사항)에 정리했습니다. 상담 뒤 직업 변경을 다시 확인할 약속은 [상담 후 기록과 다음 연락 정하기](/blog/보험-상담-후-기록-다음-연락)에서 이어집니다.

## 흔히 놓치는 점

- 직업명 하나를 보고 모든 회사의 등급을 같다고 말하는 것
- 직함은 적고 현장 업무와 운전·기계 사용을 빼는 것
- 검색 결과 첫 줄을 고객의 최종 직업으로 바로 저장하는 것
- 여러 직무 가운데 고객이 실제로 하는 일을 일부만 전달하는 것
- 직업이 바뀐 날짜와 회사 확인 기록을 남기지 않는 것

## 저장용 확인 체크리스트

- [ ] 직함보다 실제 업무와 근무 환경을 먼저 적었다
- [ ] 차량·기계 사용과 여러 직무의 비중을 확인했다
- [ ] 가입할 회사와 상품의 현재 기준을 검색했다
- [ ] 가까운 직업 항목의 설명을 나란히 비교했다
- [ ] 애매한 분류는 회사의 인수 담당 경로로 확인했다
- [ ] 확인 근거와 날짜, 이후 직업 변경 확인일을 남겼다

인파의 고객 등록과 고객 상세에서는 직업명을 검색해 가까운 직업 항목과 급수를 찾을 수 있습니다. 검색값은 첫 조회로 사용하고, 실제 업무와 가입할 회사·상품의 기준을 확인한 뒤 고객 기록에 적용하세요.
