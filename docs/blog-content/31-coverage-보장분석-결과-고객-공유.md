# 보장분석 결과를 고객에게 공유할 때, 먼저 설명할 5가지

<!-- blog-body -->

보장분석 결과를 고객에게 공유할 때는 화면의 결론부터 말하지 말고, 어떤 증권을 기준일에 등록했는지와 담보별 보장금액이 어떻게 모였는지부터 설명하세요. 설계사가 확인해 저장한 기준이 있을 때만 부족·적정·넉넉 표시의 뜻을 밝히고, 기준이 없으면 보유 금액만 함께 봅니다. 마지막에는 원문에서 더 확인할 질문과 다음 행동 하나를 남기면 됩니다.

공유 화면은 등록된 정보를 같은 틀에서 보는 참고 자료입니다. 상품을 고르거나 계약을 바꾸는 결론을 대신하지 않습니다. 숫자와 색을 설명할 때도 고객의 질문을 닫는 답이 아니라 원문을 함께 확인하는 출발점으로 사용하세요.

## 1. 어떤 자료를 언제 기준으로 정리했는지 밝힙니다

먼저 화면에 포함된 증권 이름이나 구분, 계약자·피보험자, 확인 기준일을 말합니다. 고객이 보낸 모든 계약이 들어갔다고 가정하지 말고 이번에 등록한 범위를 보여주세요. 효력이 멈춘 계약, 납입이 끝난 계약, 다른 가족의 증권이 섞였다면 합계보다 먼저 구분합니다.

“현재 가진 보험 전체”라는 표현 대신 “9월 8일까지 등록한 증권 세 건”처럼 범위를 말하면 빠진 자료를 찾기 쉽습니다. 고객이 새 증권을 보내거나 계약 상태가 달라지면 화면도 다시 확인해야 합니다.

## 2. 보장금액이 모인 방식을 보여줍니다

회사마다 다른 담보 이름은 공통 보장 항목에 연결되어 담보별 보장금액으로 모일 수 있습니다. 합계를 보여주기 전에 원래 담보명과 개별 금액을 펼쳐, 어느 증권의 어떤 줄이 포함됐는지 고객과 확인하세요.

| 설명할 순서 | 화면에서 볼 것 | 고객에게 남길 질문 |
|---|---|---|
| 자료 범위 | 등록 증권과 기준일 | 빠진 계약이나 다른 사람의 증권이 있나요? |
| 보유 금액 | 담보별 개별 금액과 합계 | 원문 금액과 단위가 같은가요? |
| 연결 결과 | 원래 담보명과 공통 보장 항목 | 지급 사유가 다른 담보가 섞이지 않았나요? |
| 설정 기준 | 설계사가 확인해 저장한 기준 | 어떤 상황과 기간을 놓고 정한 기준인가요? |
| 다음 확인 | 미상 값과 약관 질문 | 어느 문서를 누가 언제 확인할까요? |

![자료 범위부터 보유 금액, 기준, 질문과 다음 행동까지 설명하는 다섯 단계](/blog-assets/보장분석-결과-고객-공유/share-explanation-five-pending.webp)

자동으로 연결되지 않은 담보는 보장이 없다는 뜻이 아닙니다. 별도 확인 항목으로 남기고 증권과 약관에서 범위를 봅니다. 금액을 읽지 못한 줄도 0으로 채우지 말고 미상으로 표시하세요.

## 3. 기준이 있을 때만 상태 표시를 설명합니다

부족·적정·넉넉은 보편적인 정답이 아니라 화면에 적용된 기준과 등록 금액의 관계를 나타냅니다. 인파에서는 설계사가 직접 확인해 저장한 기준이 있을 때만 상태가 표시됩니다. 기준이 없으면 보유 금액만 보여주므로 색이 없는 상태를 누락이나 오류로 설명하지 않습니다.

기준이 적용됐다면 누가 언제 어떤 범위를 보고 정했는지 확인합니다. 고객의 생활비, 준비 자금, 걱정하는 상황을 대화했다고 해서 화면의 색만으로 필요한 금액이나 계약 방향이 자동으로 정해지는 것은 아닙니다. 표시와 고객 상황은 별도의 질문으로 다룹니다.

## 4. 고객이 확인할 질문을 화면 옆에 남깁니다

![고객이 등록된 보장금액과 기준 적용 여부를 함께 보는 공유 화면](/blog-assets/보장분석-결과-고객-공유/customer-share-screen-pending.webp)

고객에게 “이해하셨죠?”라고 묻기보다 화면의 빈칸을 질문으로 바꿉니다.

- 이 증권 외에 함께 확인할 계약이 있나요?
- 같은 이름으로 알고 있던 담보의 지급 조건을 원문에서 볼까요?
- 금액을 알 수 없는 항목은 어느 문서에서 확인할까요?
- 적용된 기준을 정할 때 빠진 상황이나 기간이 있나요?
- 오늘 확인하지 못한 내용은 누가 언제 답할까요?

고객이 바로 답하지 못하면 빈칸으로 남겨도 됩니다. 설계사가 추측해 채우지 말고 보험회사 공식 경로나 증권·약관에서 확인할 담당자와 날짜를 적습니다.

## 5. 공유 뒤 행동은 하나만 정합니다

화면을 보낸 뒤 여러 선택을 한꺼번에 요구하지 않습니다. 빠진 증권 한 장을 추가로 받기, 약관의 지급 조건 한 항목 확인하기, 다음 설명 날짜 잡기 가운데 현재 가장 가까운 행동 하나를 정하세요. 고객이 더 살펴보기를 원하면 질문을 남길 방법과 다시 확인할 날짜만 안내합니다.

공유 링크나 화면에는 이번 상담에 필요한 범위만 포함하고, 다른 고객 정보와 내부 메모가 보이지 않는지 전송 전에 확인합니다. 링크가 열리는 기간과 정리 방법도 실제 화면과 운영 절차에 맞춰 확인하세요.
