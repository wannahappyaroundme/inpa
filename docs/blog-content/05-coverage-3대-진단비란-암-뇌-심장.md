# 3대 진단비란? 암·뇌·심장 보장 확인 순서

<!-- blog-body -->

암·뇌·심장 진단비는 해당 질병으로 약관에서 정한 진단을 받았을 때 계약한 금액을 지급하는 정액형 보장입니다. 병원비를 쓴 만큼 돌려받는 실손의료비와 지급 방식이 다릅니다. 같은 질병군을 다루는 담보라도 이름, 보장 범위, 진단 기준, 지급 횟수는 계약마다 달라질 수 있습니다.

그래서 담보명에 암, 뇌, 심장이 들어가도 계약별 범위를 따로 확인해야 합니다. 설계사가 먼저 볼 것은 이름의 크기가 아니라 약관에 적힌 질병 분류와 지급 조건입니다.

## 세 영역을 어떻게 나눠 볼까요?

아래 구분은 증권을 읽기 위한 길잡이입니다. 실제 보장 여부는 각 계약의 약관과 증권을 기준으로 확인해야 합니다.

| 영역 | 먼저 찾을 표현 | 이어서 확인할 내용 |
|---|---|---|
| 암 | 일반암, 소액암, 유사암 등 | 어떤 질병을 따로 분류하는지, 진단 확정 기준은 무엇인지 |
| 뇌 | 뇌출혈, 뇌졸중, 뇌혈관질환 등 | 약관상 질병분류코드 범위와 제외되는 상태가 있는지 |
| 심장 | 급성심근경색, 허혈성심장질환 등 | 보장하는 질병 범위와 검사·진단 조건은 무엇인지 |

![암·뇌·심장 진단비를 범위와 지급 조건으로 확인하는 그림](/blog-assets/3대-진단비란-암-뇌-심장/diagnosis-three-areas-4697ee3c.webp)

표에서 오른쪽으로 갈수록 항상 범위가 넓다는 뜻은 아닙니다. 상품 출시 시기와 약관 정의에 따라 같은 표현도 세부 내용이 다를 수 있습니다. 질병 이름의 포함 관계를 기억하는 것보다, 해당 계약의 별표와 질병분류표를 함께 보는 편이 정확합니다.

## 금액보다 먼저 볼 네 가지

첫째, 무엇을 진단으로 인정하는지 봅니다. 의사의 진단만 필요한지, 특정 검사 결과나 병리학적 확정이 필요한지처럼 약관의 조건을 확인합니다.

둘째, 보장 개시 시점과 대기·감액 조건을 봅니다. 가입 직후부터 같은 금액이 지급된다고 단정하지 말고, 계약일과 보장 개시일을 따로 적어두세요.

셋째, 최초 1회인지 여러 번 받을 수 있는지 봅니다. 재진단, 전이, 다른 장기 발생처럼 헷갈리기 쉬운 상황도 해당 특약 문구로 확인해야 합니다.

넷째, 주계약과 특약의 만기·납입기간을 나눠 봅니다. 보험 전체가 유지되어도 특정 특약이 먼저 끝날 수 있습니다.

## 상담에서는 어떻게 설명할까요?

고객에게는 담보 이름을 길게 나열하기보다 다음 세 문장으로 시작할 수 있습니다.

1. “같은 암·뇌·심장 보장도 계약마다 포함하는 질병 범위가 달라요.”
2. “먼저 현재 증권과 약관의 범위, 지급 조건을 확인할게요.”
3. “금액은 그다음에 고객님의 필요와 부담을 함께 놓고 보겠습니다.”

질병별 표를 보여줄 때도 색이나 등급만으로 결론을 내리지 않습니다. 기준이 설정되지 않은 항목은 보유 금액만 보여주고, 기준이 있다면 그 기준이 고객 상황에 맞는지도 별도로 확인해야 합니다.

## 흔히 놓치는 점

- 담보 이름만 보고 암·뇌·심장 질병 범위의 포함 관계를 정하는 것
- 같은 진단에 연결된 여러 담보가 모두 지급된다고 가정하는 것
- 진단 확정 방법과 질병분류코드를 확인하지 않는 것
- 대기·감액 조건과 최초 1회 지급 여부를 금액표에서 빼는 것

증권에서 기본 정보를 놓치지 않으려면 [보험 증권에서 먼저 확인할 다섯 가지](/blog/보험-증권-보는-법-3분-체크리스트)를 먼저 살펴보세요. 회사마다 다른 담보명을 한 표로 정리하는 원리는 [보험 담보 이름이 다른 이유](/blog/회사마다-보험-담보-이름-다른-이유)에서 이어서 설명합니다.

## 상담 전 저장용 체크리스트

- [ ] 보장하는 질병분류코드와 약관 정의를 확인했다
- [ ] 진단 확정에 필요한 검사·의사 요건을 확인했다
- [ ] 대기기간과 감액기간, 보장 개시일을 확인했다
- [ ] 지급 횟수와 재진단 조건을 확인했다
- [ ] 주계약과 각 특약의 만기·납입기간을 나눠 적었다

인파의 보장 분석은 여러 증권의 담보명을 표준 보장 항목에 연결해 보유 금액을 한 화면에 정리합니다. 연결 결과는 확인을 돕는 출발점이며, 최종 안내에는 해당 증권과 약관의 지급 조건을 함께 사용해야 합니다.
