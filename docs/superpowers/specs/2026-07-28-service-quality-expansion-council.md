# 인파 서비스 품질 확장 페르소나 협의 기록

- 일자: 2026-07-28
- 상태: PM 추천안 승인
- 범위: 담보 기준, 화법, 프로필 성명, 게시판 본인 삭제, 무료 1개월 중복 수혜, 상담 녹음, 판촉물 예상 금액·장바구니
- 조사 기준: 운영 병합본 `origin/master`와 파일 내용이 동일한 깨끗한 작업 트리
- 원칙: 코드 구현 전에 실제 원인과 데이터 의미를 먼저 확인한다.

## 1. 확인된 사실

1. 표준 담보 트리는 이미 존재하지만 기준 설정 화면은 담보명을 직접 입력하게 한다. 현재 모델은 전연령 기본값을 표현하지 못하며 공통 담보가 판정에서 빠지는 경로가 있다.
2. 화법 30개는 프론트 정적 데이터다. 개인별 추가·수정·삭제 저장소가 없고 카드 동작은 복사만 제공한다.
3. `Profile.name`은 이미 저장 가능하지만 계정 화면에 `성명` 입력란이 없다.
4. 게시글·댓글 삭제 권한과 API는 정상이다. 프론트가 현재 사용자 ID를 계속 `null`로 두어 본인 관리 버튼을 숨긴다. 작성자 삭제 백엔드 테스트는 통과했다.
5. 무료 1개월 혜택은 사용자·쿠폰 기준으로만 중복을 제한한다. 인증된 휴대전화 식별과 탈퇴 후에도 정책 기간 동안 남는 수혜 원장이 없다.
6. 상담 녹음은 고객 본인 전자 동의를 서버에서 강제한다. 반면 녹음 직전 설계사의 구두고지 확인, 다운로드, 30일 보관은 없다. 7일 제한은 모델·설정·API·동의문·화면에 분산되어 있다.
7. 판촉물은 가격 원본, 서버 견적, 장바구니, 주문 시점 가격 기록이 없다.

## 2. 독립 페르소나 의견

### 대표·사업

- 신뢰를 훼손하는 게시판 삭제 결함과 성명 불일치를 먼저 바로잡는다.
- 담보 기준은 인파의 핵심 가치이므로 전체 담보명을 제공하되 출처가 검증되지 않은 금액을 인파 권고값처럼 노출하지 않는다.
- 화법은 가입으로 이어지는 다음 행동을 분명히 해야 하지만 과장된 성과나 보험금 지급 가능성을 주장하면 장기 신뢰를 훼손한다.
- 판촉물은 공급 가격 정책이 확정되기 전 화면용 금액을 만들지 않는다.

### 제품 기획

- 한 번의 대형 배포가 아니라 데이터와 운영 경계에 맞춰 독립 릴리스로 나눈다.
- 기준 설정은 공통 기본값을 먼저 보여주고 연령·성별 상세 기준은 필요한 사용자만 펼치게 한다.
- 무료 혜택은 회원가입 자체가 아니라 혜택 활성화 시점에 중복을 검증한다.
- 각 릴리스는 완료율과 실패율을 측정하되 고객명·메시지 본문·음성 내용은 수집하지 않는다.

### 보험설계사

- 담보명을 일일이 타이핑하지 않고 전체 목록의 오른쪽 금액만 입력하는 흐름이 필요하다.
- 화법은 `편할 때 연락`, `마음에 걸리면`으로 끝내지 않고 날짜 선택, 짧은 확인 통화, 신청 절차처럼 다음 행동을 제시해야 한다.
- 녹음 안내는 인파가 보험 가입 희망자에게 직접 보여주는 문구가 아니다. 인파가 설계사에게 읽을 문구를 제시하고, 설계사가 가입 희망자에게 직접 고지해야 한다.
- 모바일 공유가 우선이지만 데스크톱에서도 복사 기능이 항상 보여야 한다.

### UI·UX 개발

- 전체 담보 목록만 표시하면 안 된다. 공통 담보와 전연령 기준의 적용 규칙, 일괄 저장, 충돌 방지를 먼저 정의해야 한다.
- 게시판은 서버의 `can_manage`를 화면이 따르는 구조가 가장 단순하고 안전하다.
- 공유는 브라우저 기본 공유창에만 의존하지 않고 인파 공유창에 `문구 복사`를 항상 제공한다.
- 판촉물 장바구니는 서버 저장과 일괄 접수의 원자성이 필요하다.

### UI·UX·콘텐츠 디자인

- 100개 이상의 담보는 검색, 카테고리 접기, 입력한 담보만 보기로 탐색 부담을 줄인다.
- 화법은 `확인된 사실 → 고객 가치 → 작은 다음 행동 → 선택지` 구조로 통일한다.
- 녹음 고지는 적색만 사용하지 않고 아이콘, 제목, 굵은 문장, 필수 확인을 함께 사용한다.
- 기본 화법과 내 화법을 시각적으로 구분하고 기본본 복구를 제공한다.

### 보안·데이터·법무

- 현재 프로필 전화번호는 수정 가능한 비인증 연락처이므로 중복 혜택 식별키로 쓰지 않는다.
- SMS로 확인된 번호의 원문 대신 HMAC 식별값을 별도 원장에 저장하고, 원장은 계정 탈퇴와 분리한다.
- SMS 인증은 번호 통제만 확인하며 사람을 영구 식별하지 못한다. 이번 무료 혜택에는 SMS+수동심사를 사용하되 `개인 평생 고유번호`라고 표현하지 않는다.
- 상담 녹음 다운로드는 소유자 전용의 짧은 만료 주소와 감사 이벤트가 필요하다.
- 기존 7일 동의로 생성된 녹음의 만료일은 30일로 연장하지 않는다.
- 판촉물 총액은 서버가 계산하고 주문 제출 시점 값을 변경 불가능한 기록으로 남긴다.

### QA·CS·재무·그로스

- 게시판 목록·상세·댓글에서 본인 버튼 노출과 타인 API 강제 호출을 함께 검증한다.
- 번호 재할당·공용번호·이전 계정 사례를 처리할 관리자 심사함과 처리 이력이 필요하다.
- 신규 30일과 기존 7일 경계를 실제 시간·정리 작업으로 검증한다.
- 30일 원본 보관은 7일 대비 정상상태 저장량이 약 4.3배이므로 저장량과 다운로드 트래픽을 관찰한다.
- 화법의 성장 효과는 메시지 본문이 아니라 템플릿 ID, 공유·복사·다음 단계 전환 이벤트로 측정한다.

## 3. 토론 1라운드: 빠른 화면 변경안 공격

### 담보 기준

- 공격: 전체 담보 카드만 추가하면 공통 담보와 전연령 값이 실제 판정에서 빠질 수 있다.
- 방어: 표준 담보 ID, 공통 기본값, 상세 예외 우선순위와 일괄 저장을 같은 릴리스에 포함한다.
- 합의: 인파는 담보명·분류·단위만 제공하고 금액은 빈칸으로 둔다.

### 가입 전환 화법

- 공격: `부담 갖지 마세요`, `편할 때`, `결정은 고객님 몫`은 거절과 무기한 연기를 만든다.
- 반격: `유리하다`, `보험료가 줄었다`, `받을 수 있는 돈` 같은 단정은 실제 분석 결과 없이 사용할 수 없다.
- 합의: 다음 행동은 적극적으로 제시하고 결과·우월성·지급 가능성은 단정하지 않는다.

### 무료 혜택

- 공격: 프로필 휴대전화에 `unique`만 추가하면 인증되지 않은 번호로 정상 사용자를 막고 우회도 허용한다.
- 방어: 가입은 허용하고 무료 혜택 직전에 SMS 인증 번호를 확인한다.
- 합의: 인증 번호 HMAC 원장+관리자 수동심사를 채택하고 PASS/CI는 이번 범위에서 제외한다.

### 상담 녹음

- 공격: 적색 문구만 화면에 보이는 것은 설계사가 실제로 가입 희망자에게 고지했다는 확인이 아니다.
- 방어: 고객 본인 전자 동의에 더해 매 녹음 시작 전 설계사의 구두고지 완료 확인을 서버에 기록한다.
- 합의: 인파 화면의 청자는 설계사다. 설계사가 가입 희망자에게 읽을 문구와 필수 확인을 제공한다.

### 판촉물

- 공격: 프론트에서 임의 금액을 합산하면 가격 조작과 주문 분쟁이 발생한다.
- 방어: 공급 가격표를 받은 뒤 서버 가격과 장바구니를 함께 만든다.
- 합의: 가격표를 받을 때까지 구현을 보류하고 구조만 설계한다.

## 4. 토론 2라운드: 운영 복잡도와 최종 경계

1. 게시판 소유자 판정은 클라이언트 사용자 ID 비교보다 서버 `can_manage`를 사용한다.
2. 기준은 모든 담보를 제공하되 입력된 값만 저장한다. 기본값과 상세 예외의 적용 순서를 고정한다.
3. 기본 화법은 운영 원본, 사용자는 복제한 `내 템플릿`만 수정·삭제한다. 기본 화법은 숨김과 복구를 제공한다.
4. 공유는 인파 공유창을 먼저 열고 `문구 복사`를 항상 제공한다. 지원 기기에서만 시스템 공유창을 추가한다.
5. 무료 혜택은 SMS 인증 번호 기준으로 같은 무료 1개월 혜택을 한 번만 제공한다. 중복·재할당·공용번호는 관리자 심사로 처리한다.
6. 녹음은 기존 고객 본인 동의와 설계사의 매회 구두고지 확인을 모두 만족해야 시작한다.
7. 신규 녹음만 새 동의문으로 30일 보관한다. 기존 녹음은 기존 7일을 유지한다.
8. 판촉물은 가격표 수령 후 `예상 금액 + 견적 장바구니`로 만들고 결제는 포함하지 않는다.

| 2 | 담보 전체 기준표·기준 적용 규칙 | 9.2 | 핵심 분석 데이터 릴리스 |
| 3 | 화법 교정·내 템플릿·공유 | 9.0 | 전환과 개인화 릴리스 |

## 6. 승인된 최종 결정

- 추천 릴리스 분리안을 채택한다.
- 담보 전체 목록을 제공하고 금액은 빈칸으로 둔다.
- 공통 기준을 기본으로, 연령·성별 상세 기준을 선택적으로 제공한다.
- 화법 30개를 전면 교정하고 내 템플릿 CRUD와 공유·복사를 제공한다.
- 프로필 라벨을 `성명`으로 중앙화한다.
- 게시판은 서버 `can_manage`로 본인 수정·삭제를 표시한다.
- 무료 1개월은 SMS 인증 번호 기준 1회+관리자 수동심사로 운영한다.
- 녹음 고지는 설계사가 보험 가입 희망자에게 직접 읽는 안내문이다.
- 신규 녹음은 30일, 기존 녹음은 기존 7일을 유지한다.
- 90일·장기 보관은 로드맵만 남긴다.
- 판촉물 구현은 PM이 공급 가격표를 한 번에 전달할 때까지 보류한다.
