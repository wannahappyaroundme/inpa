# 인파 블로그 무료 자료 탭 설계

## 1. 목적

현재 각각 독립 주소로 공개된 보험나이 계산기, 고객 관리표 빈 양식, 첫 상담 체크리스트를 `인파 블로그` 안의 `무료 자료` 탭에서 한 번에 찾을 수 있게 한다. 검색과 외부 공유에 쓰이는 기존 자료 주소는 유지하면서, 방문자가 이해하는 정보 구조만 블로그 중심으로 정리한다.

### 확정 명칭

- 블로그 브랜드명: `인파 블로그`
- 자료 탭명: `무료 자료`
- 새 화면과 현재 문서에서는 확정 명칭만 사용한다.
- 과거 의사결정 기록의 파일명과 원문은 이력 보존을 위해 일괄 수정하지 않는다. 대신 현재 기준 문서에 명칭 규칙을 명시해 이후 작업에서 재사용되지 않게 한다.

## 2. 검토한 방식

| 방식 | 장점 | 단점 | 결정 |
|---|---|---|---|
| `/blog/resources` 독립 경로를 블로그 탭처럼 표시 | 직접 공유와 검색 색인이 쉽고, 탭 활성 상태가 주소에 남으며, 블로그 글 목록과 자료 화면을 분리해 관리하기 쉽다 | 페이지 파일과 공용 탭 컴포넌트가 하나 추가된다 | 채택 |
| `/blog?tab=resources` 쿼리 탭 | 새 경로가 필요 없다 | canonical, 공유 주소, 서버 렌더 분기가 복잡해지고 글 카테고리 쿼리와 섞인다 | 제외 |
| `/blog` 한 화면에 자료를 함께 배치 | 구현이 가장 단순하다 | 사용자가 요청한 두 개의 명확한 탭이 아니며 글 목록이 길어진다 | 제외 |

## 3. 정보 구조와 이동 경로

### 공개 메뉴

- 공개 사이트 상단 메뉴의 `무료 도구` 항목은 제거한다.
- `블로그` 메뉴는 유지하고 `/blog`로 연결한다.
- 홈페이지의 자료 카드 영역은 검색과 발견성을 위해 유지한다. 화면 제목은 `무료 자료` 계열의 쉬운 표현으로 맞추고, 각 카드는 기존 자료 주소로 바로 연결한다.

### 인파 블로그

블로그 공통 상단에 두 개의 1차 탭을 둔다.

1. `인파 블로그`: `/blog`
2. `무료 자료`: `/blog/resources`

`/blog`에서는 기존 글 카테고리 필터를 2차 탐색으로 유지한다. `전체`, `고객 늘리기`, `보장분석`, `안심 가이드`, `설계사 이야기`는 `인파 블로그` 탭 안에서만 보인다.

`/blog/resources`에서는 다음 세 카드를 노출한다.

1. 보험나이 계산기 → `/tools/insurance-age`
2. 고객 관리표 빈 양식 → `/resources/customer-management-sheet`
3. 첫 상담 체크리스트 → `/resources/consultation-checklist`

각 카드에는 자료 종류, 제목, 한 줄 설명, 바로 실행하는 버튼을 넣는다. 기존 `PUBLIC_RESOURCES` 데이터를 재사용해 홈페이지와 블로그의 제목·설명이 어긋나지 않게 한다.

## 4. 화면 설계

### 공통 헤더

- 로고 옆 이름을 `인파 블로그`로 표시한다.
- 모바일에서도 두 탭이 한 줄에서 명확히 눌리며, 현재 탭은 색과 `aria-current`로 함께 구분한다.
- `무료로 시작하기` 버튼은 기존처럼 유지한다.

### 인파 블로그 탭

- 제목: `인파 블로그`
- 기존 소개 문장, 글 카드, 오류·빈 상태, 페이지 이동을 유지한다.
- 1차 탭과 글 카테고리 필터가 같은 수준으로 보이지 않도록 간격과 형태를 구분한다.

### 무료 자료 탭

- 제목: `무료 자료`
- 소개: 가입 전에도 바로 써볼 수 있는 계산기와 빈 양식, 체크리스트를 한곳에 모았다는 내용으로 쓴다.
- 카드 3개는 데스크톱 3열, 태블릿 2열, 모바일 1열로 배치한다.
- 계산과 체크 상태를 저장하거나 서버로 보내지 않는다는 안내는 한 번만 간결하게 제공한다.
- 자료가 코드에 고정된 정적 목록이므로 로딩·빈 상태는 만들지 않는다. 링크는 기존 자료 화면의 오류 처리와 동작을 그대로 사용한다.

## 5. 검색과 주소 정책

- `/blog/resources`는 독립 canonical과 검색 허용 메타데이터를 가진다.
- 사이트맵에 `/blog/resources`를 추가한다.
- 기존 세 자료 주소와 canonical은 바꾸지 않는다. 기존 검색 결과와 외부 링크가 끊기지 않는다.
- 같은 설명을 여러 주소에 길게 복제하지 않고, `/blog/resources`는 자료 모음 페이지 역할만 한다.
- `인파 블로그`, `무료 자료` 명칭을 제목, OG 정보, 접근성 이름에 일관되게 사용한다.

## 6. 변경 범위

- 블로그 공용 1차 탭 컴포넌트 추가
- `/blog` 명칭과 탭 구조 정리
- `/blog/resources` 자료 모음 페이지 추가
- 공개 사이트 메뉴에서 `무료 도구` 제거
- 홈페이지 자료 영역의 사용자 노출 명칭을 `무료 자료`로 정리
- 사이트맵과 관련 테스트 갱신
- 현재 기준 문서인 `README.md`, `AGENTS.md`에 명칭 규칙과 배포 결과 반영

관리자 블로그 작성 기능, 게시글 데이터 구조, 기존 자료의 계산·다운로드·체크 기능은 변경하지 않는다.

## 7. 검증 기준

- `/blog`에서 `인파 블로그` 탭이 활성화되고 기존 글 목록과 카테고리 필터가 동작한다.
- `/blog/resources`에서 `무료 자료` 탭이 활성화되고 세 카드가 정확한 기존 주소로 이동한다.
- 공개 사이트 상단에 `무료 도구` 메뉴가 남지 않는다.
- 사용자에게 보이는 블로그·자료 명칭이 각각 `인파 블로그`, `무료 자료`로 통일된다.
- 세 기존 자료 주소의 canonical과 동작이 바뀌지 않는다.
- 모바일 375px과 데스크톱에서 탭, 카드, 버튼이 잘리지 않는다.
- 프론트 테스트, 복사 문구 검사, Next.js 운영 빌드가 통과한다.
- Preview에서 `/blog`, `/blog/resources`, 세 자료 경로를 직접 확인한 뒤 운영 배포 승인을 받는다.

## 8. 배포와 되돌리기

- 데이터베이스와 백엔드 변경은 없다.
- Preview 검증 후 운영 배포는 별도 승인 뒤 진행한다.
- 문제가 생기면 프론트 배포를 직전 Vercel 버전으로 되돌리면 된다. 기존 자료 주소는 그대로이므로 자료 자체의 접근에는 영향이 없다.
