# test@inpa.kr 상담 녹음·OpenAI 메모 파일럿 설계

**승인일:** 2026-07-29  
**승인 범위:** `test@inpa.kr` 한 계정에서 실제 녹음, OpenAI 전사·요약, 고객 메모 저장까지 운영 검증

## 1. 목표

설계사가 고객 상세 화면의 기록 탭에서 상담을 녹음하고, 녹음 파일당 한 번만 OpenAI 요약을 만들어 여러 고객 메모 중 하나로 저장한다. 생성 뒤에는 일반 메모처럼 설계사가 직접 수정할 수 있으며, AI 재요약은 제공하지 않는다.

이번 출시는 공개 기능 전환이 아니다. 기존 시연 계정의 외부 호출 차단은 유지하되, 정확히 `test@inpa.kr`의 상담 녹음·요약만 별도 환경 안전판과 사용자별 권한이 모두 켜졌을 때 허용한다.

## 2. 사용자 흐름

1. 설계사가 고객 상세의 `기록 > 메모`에서 `상담 녹음`을 시작한다.
2. 고객 본인의 최신 상담 녹음·민감정보·국외 처리 동의가 없으면 동의 링크를 먼저 보낸다.
3. 녹음을 끝내면 비공개 R2 경로에 분할 업로드한다.
4. 녹음 카드에서 `OpenAI로 핵심 메모 만들기`를 한 번 누른다.
5. 백그라운드 작업이 화자 구분 전사, 개인정보 가림, 구조화 요약을 순서대로 수행한다.
6. 성공하면 날짜·시간을 가진 새 메모가 고객의 메모 목록에 추가된다.
7. 설계사는 생성된 메모를 직접 수정하거나 삭제할 수 있다. 같은 녹음의 재요약 버튼은 나타나지 않는다.
8. 원본 녹음은 최대 7일만 보관한 뒤 자동 삭제된다. 메모는 고객 기록으로 계속 남는다.

## 3. 접근 제어

상담 기능은 다음 세 안전판을 모두 통과해야 한다.

- 운영 환경: 녹음, AI 요약, 시연 계정 상담 파일럿 플래그
- 운영 관리자 설정: 녹음, AI 요약 스위치
- 사용자별 권한: 녹음 허용, 요약 허용

시연 계정 예외는 `SHOWCASE_ACCOUNT_EMAIL`과 `Profile.is_showcase=True`가 함께 일치하는 계정에만 적용한다. 이 예외는 상담 API에만 적용하며 이메일, 결제, 보험 분석 등 기존 시연 계정 외부 작업 차단에는 영향을 주지 않는다.

다른 일반 사용자에게는 사용자별 권한이 없으면 기능이 보이지 않는다. 공개 확대는 이번 범위에 포함하지 않는다.

## 4. AI 처리와 한 번 요약 보장

### 전사

- 공급자: OpenAI
- 모델: 운영 환경의 `OPENAI_TRANSCRIPTION_MODEL`
- 응답: `diarized_json`, `chunking_strategy=auto`, 한국어
- 화자 표기: 공급자 화자 ID를 `화자 1`, `화자 2`처럼 안정적으로 변환

### 요약

- 공급자: OpenAI Responses API
- 모델: 운영 환경의 `OPENAI_CONSULTATION_SUMMARY_MODEL`
- 출력: 기존 상담 요약 JSON 스키마를 강제
- 저장 정책: `store=False`
- 입력: 이름, 전화번호, 이메일 등 직접 식별자를 가린 전사문

`ConsultationSummaryRun.recording`의 일대일 제약과 상태 전이 잠금으로 녹음당 요약 실행을 하나만 만든다. 공급자 호출 전에 예약 시각을 기록하며, 응답 여부를 확정할 수 없는 시간 초과는 자동 재호출하지 않고 `확인 필요` 상태로 닫아 이중 과금을 막는다. 연결조차 되지 않았음이 명확한 경우만 최대 3회 지수 재시도한다.

전사 원문과 개인정보를 가린 전사문은 데이터베이스와 로그에 저장하지 않는다. 성공 결과만 고객 메모로 저장한다.

## 5. 데이터와 보관

R2 키는 기존처럼 소유자 UUID, 고객 UUID, 녹음 UUID가 포함된 서버 생성 경로를 사용한다. 모든 조회와 변경은 중앙 소유권 필터를 통과한다.

새 녹음은 보관 정책 `v3-7d`를 사용한다.

- `retention_hours_snapshot=168`
- `retention_days_snapshot=7`
- `expires_at=업로드 완료 시각 + 168시간`
- 고객·설계사 고지문 버전과 문구 해시를 녹음 행에 고정

기존 `v1-7d`, `v2-30d` 녹음의 당시 고지와 보관 스냅샷은 변경하지 않는다. 새 마이그레이션은 `v3-7d`에 정확한 7일 값과 최신 고지 증거가 있을 때만 저장되도록 DB 제약을 추가한다.

Cloudflare R2 수명 주기는 애플리케이션의 정확한 삭제를 보완하는 안전망이다. 화면에는 실제 정책과 맞게 `원본 녹음은 최대 7일 보관`이라고 표시한다.

## 6. 화면

- 녹음 영역은 기존 인파 고객 상세 UI의 카드, 색상, 모바일 레이아웃을 그대로 따른다.
- 파일럿 계정에는 `OpenAI로 핵심 메모 만들기`라고 공급자를 명확히 표시한다.
- 진행 상태는 `녹음 올리는 중`, `상담 내용 정리 중`, `메모 저장 완료`, `다시 확인해 주세요`처럼 쉬운 말로 표시한다.
- 빈 상태, 업로드 중, 실패, 동의 필요, 만료 상태를 모두 제공한다.
- 성공 메모는 기존 여러 메모 목록에 추가되며 별도 단일 메모 칸을 만들지 않는다.

## 7. 관측과 비용

각 실행에는 공급자, 모델, 입력·출력 토큰, 전체 처리 시간, 성공·실패 결과 코드, 추정 비용을 기록한다. 관리자 화면은 원문 없이 이 값만 보여준다.

운영 확인은 개인정보가 없는 짧은 합성 상담 음성 한 건으로 한다. 실제 유료 OpenAI 호출이 성공해 새 고객 메모가 만들어지고, 동일 녹음의 두 번째 요약 요청이 차단되는 것까지 확인한다.

## 8. 비범위

- 모든 설계사에게 기능 공개
- 녹음 실시간 스트리밍 전사
- 전사 원문 영구 저장 또는 검색
- 같은 녹음의 재요약
- AI가 수정된 메모를 다시 덮어쓰기
- 클루드와 OpenAI 비교 결과를 고객 메모에 자동 반영

## 9. 완료 기준

- `test@inpa.kr`에서 녹음 버튼과 OpenAI 요약 버튼이 보인다.
- 고객 본인 동의 없이는 녹음·요약이 시작되지 않는다.
- 녹음 한 건에서 메모가 정확히 한 개 만들어진다.
- 생성 메모는 수정 가능하고 여러 메모 목록에 날짜·시간 순으로 나타난다.
- 같은 녹음의 재요약은 API와 화면에서 모두 막힌다.
- 새 녹음은 최대 7일 정책과 삭제 감사 기록을 가진다.
- 다른 시연 계정과 권한 없는 일반 계정은 닫혀 있다.
- 백엔드·프런트 전체 테스트, 빌드, 마이그레이션, 운영 API와 실제 화면 확인이 통과한다.
