# 랜딩 Manager 문구·시연 영입 안내 설계

## 목표

운영 동작과 랜딩 설명을 일치시킨다.

- Manager를 별도 유료 상품이 아니라 Plus 사용 중 첫 설계사 합류 시 열리는 역할로 안내한다.
- 랜딩 상단은 `블로그`, `로그인`, `무료로 시작하기`에 집중한다.
- 내부 시연 계정이 외부 영입 기능 차단 때문에 일반 오류 화면을 보지 않도록, 차단은 유지하면서 시연용 안내와 내부 현황을 보여준다.

## 범위

### 포함

1. 공용 요금표를 `무료 / Plus / Super` 3단으로 변경
2. Plus 기능 목록에 다음 문구 추가
   - `첫 설계사 합류 시 Manager 역할 자동 활성화`
   - `팀원과 팀 전체 흐름 관리`
3. 요금제 제목을 `인파 요금제`로 변경
4. 서비스 랜딩 상단 메뉴를 다음 세 항목으로 단순화
   - `블로그`
   - `로그인`
   - `무료로 시작하기`
5. 랜딩의 `인파 노트` 표기를 `블로그`로 통일
6. 시연 계정에서 `SHOWCASE_ACTION_RESTRICTED`가 발생하면:
   - 영입 요약과 지원자 목록은 계속 불러온다.
   - 외부 공개 페이지·캠페인 기능만 제한 상태로 취급한다.
   - 일반 재시도 오류 대신 `시연 계정에서는 등록된 자료로 영입 흐름을 확인할 수 있어요.`를 표시한다.

### 제외

- 증권 검토형 자동 정리 공지·FAQ 추가
- 보험 검토 기능 게이트 변경
- 요금·한도·결제 데이터 모델 변경
- 시연 계정의 공개 영입 페이지, 캠페인 링크, 팀 연결 차단 해제
- 프로필 API에 `is_showcase` 노출
- 운영 데이터 생성·삭제

## 설계 선택

### 채택: 프론트엔드에서 제한된 선택 기능만 분리 처리

`StatusPanel`은 영입 요약·지원자 목록과 공개 페이지·캠페인 정보를 독립적으로 처리한다. 공개 기능 요청만 `SHOWCASE_ACTION_RESTRICTED`로 실패하면 전체 화면 오류로 올리지 않고 제한 상태로 저장한다.

장점:

- 기존 백엔드 보안 경계를 유지한다.
- 일반 계정의 오류 처리는 바꾸지 않는다.
- 시연 계정에서도 내부 영입 현황을 확인할 수 있다.
- 서버에 새 필드나 마이그레이션이 필요 없다.

### 제외안 1: 프로필 API에 시연 계정 플래그 노출

프론트엔드 분기는 쉬워지지만 내부 계정 분류 정보가 일반 프로필 계약에 섞인다. 현재 서버가 의도적으로 숨기는 값을 노출하므로 제외한다.

### 제외안 2: 시연 계정의 공개 영입 GET 허용

화면 오류는 사라지지만 공개 경로와 팀 연결을 차단한 시연 계정의 보안 원칙을 약화한다. 외부 작동 없는 읽기 요청도 공개 토큰 생성 상태와 연결되므로 제외한다.

## 화면 동작

### 랜딩

- 데스크톱과 모바일 모두 같은 3개 상단 메뉴를 사용한다.
- 별도 햄버거 메뉴를 제거한다.
- Plus 카드 한 곳에서 개인 업무와 Manager 역할을 함께 설명한다.
- `19,900원`은 Plus에 한 번만 노출한다.

### 시연 계정 설계사 영업

- 요약·지원자 목록 로딩은 정상 진행한다.
- 공개 페이지·캠페인 요청이 시연 제한으로 실패하면 제한 안내를 저장한다.
- 지원자가 없으면 일반 영입 시작 CTA 대신 시연 안내 카드를 표시한다.
- 지원자가 있으면 현황을 그대로 표시하고, 공개 링크 복사 CTA만 노출하지 않는다.
- 네트워크 오류, 인증 오류, 서버 오류는 기존 오류 화면과 재시도를 유지한다.

## 오류 처리

- 제한 여부 판정은 `ApiError.code === "SHOWCASE_ACTION_RESTRICTED"`만 사용한다.
- 403 전체를 시연 제한으로 간주하지 않는다.
- 영입 요약 실패는 기존 전체 오류다.
- 공개 페이지·캠페인 중 시연 제한이 아닌 오류도 기존 전체 오류다.

## 테스트

1. 요금표 렌더 테스트
   - Manager 별도 카드 없음
   - Plus와 Super 존재
   - Manager 자동 활성화 문구 존재
   - `19,900원` 한 번만 노출
2. 서비스 랜딩 테스트
   - 상단에 블로그·로그인·무료 시작만 존재
   - 기존 앵커 메뉴와 햄버거 버튼 없음
   - 푸터 `블로그` 표기
3. 영입 현황 테스트
   - 공개 페이지·캠페인 요청이 `SHOWCASE_ACTION_RESTRICTED`여도 일반 오류를 표시하지 않음
   - 시연 안내 문구 표시
   - 요약·지원자 목록은 표시
   - 일반 오류는 기존 재시도 오류로 유지
4. 전체 프론트엔드 테스트, 복사 문구 검사, Next.js 빌드
5. 데스크톱·모바일 실제 렌더에서 랜딩과 시연 영입 화면 확인

## 성공 기준

- 운영 랜딩에 요금제 카드가 정확히 3개 보인다.
- Plus 카드에 Manager 자동 활성화 문구가 보인다.
- 상단 메뉴에 기존 앵커 메뉴와 햄버거가 없다.
- 시연 계정 `/sales?tab=recruiting`에서 일반 오류 대신 시연 안내와 영입 현황이 보인다.
- 일반 계정 API 오류 동작과 시연 계정 보안 차단은 유지된다.
