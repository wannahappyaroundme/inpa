# 인파 영업·마케팅 실행판 설계

작성일: 2026-08-02

## 1. 목적

두 명의 운영자가 2026년 8월 3일부터 12월 31일까지 서울에서 시작해 수도권·충청·영남·호남으로 영업을 확장하며, 원수사 소속 관리직과 중견 설계사를 만나 인파를 실제로 사용하게 하고 반복 피드백 사용자 20명을 확보한다.

이 실행판은 계획을 읽는 문서가 아니라 매일 열어 체크하고 수정하는 단일 HTML 업무 화면이다. 별도 서버나 로그인 없이 파일을 브라우저에서 열어 사용한다.

## 2. 성공 기준

- 최종 반복 사용자 20명
- 설계파트너 신청 60명
- 7일 안에 첫 사용 완료 42명
- 14일 안에 재사용 30명
- 6주 사용 완료 24명
- 실제 방문 영업 거점 28곳
- 지점장·팀장 대면 45명 이상
- 소개받은 중견 설계사 100명 이상

최종 반복 사용자는 최소 6주 참여, 서로 다른 주에 의미 있는 사용 6회 이상, 핵심 흐름 2개 이상 경험, 피드백 3회 이상, 마지막 4주 중 3주 이상 활동, 최근 30일 이내 사용을 모두 충족한 사람으로 정의한다.

## 3. 대상과 영업 원칙

- 1순위: 생명보험·손해보험 원수사 지점장, 지사장, 팀장
- 2순위: 관리직이 소개한 2~3년 이상 중견 설계사
- 보조 대상: 소개를 통해 적합성이 확인된 GA 설계사 최대 2명
- 관리직은 팀 가입 결정자가 아니라 방문 허가자, 소개자, 직접 사용 가능자로 취급한다.
- 첫 설명은 가상 자료로 진행하며, 실제 고객정보는 고객 동의와 소속사 기준이 확인된 경우에만 인파 안에서 처리한다.
- 가입, 소개, 후기와 선물을 연동하지 않는다.
- 연락 중단을 요청한 대상은 즉시 종료하고 재접촉하지 않는다.

## 4. 화면 구성

### 4.1 상단 현황

- 캠페인 기간과 최종 목표
- 오늘 날짜 기준 남은 일수
- 전체 체크리스트 완료율
- 핵심 KPI 목표·실적·달성률
- 현재 가장 부족한 KPI 안내

### 4.2 오늘 할 일

- 오늘 날짜에 해당하는 일정 자동 표시
- 완료 체크, 담당자, 실제 수치, 메모 수정
- 새 할 일 추가와 기존 할 일 삭제
- 미완료 업무를 다음 날짜로 복제

### 4.3 날짜별 실행계획

- 2026-08-03부터 2026-12-31까지 주차별 실행 항목 제공
- 준비, 전화·문자, 방문, 설명, 첫 사용 지원, 인터뷰, 재방문, 지역 출장으로 구분
- 각 항목의 날짜, 권역, 행동, 목표 수치, 실제 수치, 담당자, 상태, 메모를 편집 가능하게 제공
- 월별 접기·펼치기와 미완료만 보기 제공

### 4.4 영업 대상 관리

- 회사, 영업 거점, 지역, 직책, 이름, 연락 경로, 현재 단계, 다음 행동일, 소개자, 메모
- 단계: 조사, 연락 예정, 자료 전달, 일정 확정, 방문 완료, 설계사 소개, 설계파트너, 첫 사용, 재사용, 6주 완료, 최종 사용자, 중단
- 행 추가·삭제와 모든 칸 직접 수정
- 단계별 대상 수를 KPI에 자동 합산

### 4.5 설계파트너 관리

- 이름, 회사·지점, 역할, 경력, 시작일, D2·D7·D14·D30·D42 일정, 의미 있는 사용 횟수, 핵심 흐름 수, 피드백 횟수, 최근 사용일
- 최종 사용자 조건 충족 여부 자동 판정
- 다음 후속일이 지난 사람 강조

### 4.6 영업 시나리오 모음

실행자가 상황에 맞춰 선택할 수 있도록 다음 시나리오를 제공한다.

1. 대표번호 연락 후 자료 전달과 방문 예약
2. 종이 방문 요청서 직접 전달
3. 예약 없는 영업 거점 안내 데스크 방문
4. 지점장 1:1 30분 설명
5. 팀장 1:1 20분 설명
6. 관리직이 함께 참여하는 소규모 설명
7. 중견 설계사 4~6명 미니 설명회
8. 점심시간 20분 화면 시연
9. 아침 조회 전후 15분 설명
10. 퇴근 전 20분 설명
11. 기존 관리직의 다른 지점장 소개
12. 생명보험 관리직의 손해보험 관리직 교차 소개
13. 사용 설계사의 동료 1명 소개
14. 지역 출장 전 온라인 사전 설명
15. 지방 2일 1박 묶음 방문
16. 첫 방문 후 D2 가입·첫 설정 지원
17. D7 첫 사용 확인
18. D14 커피 심층 인터뷰
19. D30 반복 사용 인터뷰
20. D42 최종 사용자 판정
21. 사용 중단자의 이탈 이유 인터뷰
22. 활발한 사용자 4~6명 공동 피드백 모임
23. 관리직 대상 월간 사용 결과 공유
24. 인스타그램 화면 영상에서 설명 신청 받기
25. 현장 질문을 인파 노트 글로 바꿔 신뢰 자료로 활용
26. 소개받은 대상에게 1:1 전화·문자로 일정 확정
27. 지역별 반응이 좋은 사용자의 재방문 동행 요청
28. 12월 최종 사용자 감사 인터뷰와 다음 분기 참여 확인

각 시나리오는 목표, 준비물, 실행 순서, 성공 기준, 중단 기준, 후속 행동을 모두 수정 가능하게 제공한다.

### 4.7 KPI와 주간 검토

- 공식 접촉 거점
- 자료 전달 허락
- 방문 확정
- 실제 방문
- 관리직 대면
- 설계사 소개
- 개인 설명
- 설계파트너 신청
- 첫 사용
- 14일 재사용
- 6주 완료
- 최종 반복 사용자
- 관리직 소개 발생
- 지역 출장당 설계파트너

목표값과 실제값은 모두 수정 가능하다. 영업 대상·설계파트너 표의 단계와 실제 수치를 합산해 실적을 계산하며, 사용자가 직접 덮어쓸 수 있는 수동 실적 칸도 둔다.

### 4.8 주간 회고

- 이번 주 가장 잘된 접촉 방식
- 가장 많이 나온 거절 이유
- 첫 사용을 막은 이유
- 다음 주 중단할 행동
- 다음 주 두 배로 늘릴 행동
- 제품에 반영할 피드백

모든 항목은 자유롭게 작성하고 주차별로 보관한다.

- 8월 10~31일: 서울 주 4개 거점 방문, 주 6명 관리직 대면, 주 3명 설계파트너 확보

## 6. 편집과 저장

- 제목, 설명, 표의 모든 셀, KPI 목표, 날짜, 시나리오를 화면에서 직접 수정한다.
- 체크박스, 텍스트, 숫자, 추가한 행을 브라우저 `localStorage`에 즉시 저장한다.
- 저장 상태와 마지막 저장 시각을 표시한다.
- JSON 파일로 전체 데이터를 내보내고 다시 불러올 수 있게 한다.
- 기본 계획 복원은 확인 절차를 거친다.
- 브라우저 인쇄에서 완료 상태와 핵심 KPI가 읽히도록 한다.

## 7. 구현 제약

- 단일 HTML 파일로 작성한다.
- 외부 서버, API, 로그인, 빌드 과정이 없어야 한다.
- 외부 라이브러리를 사용하지 않는다.
- 데스크톱, 태블릿, 모바일에서 겹침 없이 사용할 수 있어야 한다.
- 키보드로 체크박스와 입력칸을 사용할 수 있어야 한다.
- 기존 인파 서비스 코드와 배포에는 연결하지 않는다.
- 스팸 규정 설명, 링크드인 정책, 네이버 스팸메일 관련 설명과 링크는 화면에 넣지 않는다.

## 8. 검증

- 파일을 직접 열었을 때 오류 없이 표시되는지 확인한다.
- 모든 기본 일정과 시나리오가 표시되는지 확인한다.
- 체크, 수정, 추가, 삭제 후 새로고침해도 유지되는지 확인한다.
- JSON 내보내기와 불러오기로 동일 상태가 복원되는지 확인한다.
- KPI 목표와 실제값, 달성률이 일치하는지 확인한다.
- 모바일 폭에서 표와 조작부가 잘리거나 겹치지 않는지 확인한다.
- 인쇄 미리보기에서 불필요한 조작 버튼이 숨겨지는지 확인한다.

## 9. 2026-08-02 체크리스트·캘린더 우선 개편

### 9.1 첫 화면

- 상단 소개 영역 바로 아래에 오늘 할 일 체크리스트를 가장 먼저 배치한다.
- 오늘 업무는 완료 체크, 행동, 담당자, 목표·실적, 메모를 한 화면에서 수정한다.
- 오늘보다 이전 날짜의 미완료 업무가 있으면 오늘 목록 위에 별도 묶음으로 표시한다.
- 오늘 업무가 없으면 캠페인 기간 안에서 가장 가까운 다음 실행일과 그날의 업무를 안내한다.
- 전체 KPI 현황은 오늘 체크리스트와 캘린더 다음으로 이동한다.

### 9.2 월간 캘린더

- 기존 월별 표 중심 일정 화면을 일요일부터 토요일까지 7열인 월간 캘린더로 교체한다.
- 각 날짜 칸에 핵심 업무를 최대 3개까지 체크박스와 함께 직접 표시한다.
- 업무가 3개보다 많으면 남은 개수를 표시한다.
- 날짜를 누르면 캘린더 아래의 선택 날짜 상세 체크리스트가 갱신된다.
- 이전 달, 다음 달, 오늘 이동을 제공하며 선택한 달과 날짜를 브라우저 저장 데이터에 보관한다.
- 데스크톱은 월간 전체를 한 화면에 표시한다. 모바일은 날짜 칸의 읽을 수 있는 너비를 유지한 가로 스크롤 월간 캘린더를 제공한다.
- 캘린더 안에서 체크한 완료 상태는 오늘 체크리스트와 선택 날짜 상세 목록에 즉시 반영된다.

### 9.3 데이터와 호환성

- 기존 `inpa-sales-marketing-execution-v1` 저장 키와 상태 구조를 유지한다.
- 이미 수정한 일정, 체크 상태, KPI, 대상, 설계파트너, 시나리오, 회고를 초기화하지 않는다.
- `settings.calendarMonth`와 `settings.selectedDate`가 없는 기존 저장 데이터는 현재 날짜 또는 캠페인 시작일을 기준으로 안전하게 채운다.
