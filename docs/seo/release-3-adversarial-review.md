# 검색·AI 성장 릴리스 3 다각도 검토

검토일: 2026-08-03
범위: 보험나이 계산, 공개 자료 3종, 유입 분류, 관리자 채널 퍼널, 사용 이벤트, 색인과 내부 링크

## 발견하고 수정한 항목

| 우선순위 | 관점 | 발견 | 수정과 회귀 방지 |
|---|---|---|---|
| 중요 | 측정 정확성 | 과거 `utm_source=chatgpt.com`처럼 도메인 형태로 저장된 값이 기타로 묶일 수 있었음 | 검색·AI의 안전한 도메인 별칭을 FE와 BE에 같은 목록으로 추가하고 `chatgpt.com`, `perplexity.ai`, `claude.ai` 분류 테스트 추가 |

## 확인 결과

- 날짜 계산: 월말, 정확히 6개월, 윤년 2월 29일, 미래 날짜, 잘못된 날짜를 Python과 TypeScript 골든 값으로 맞췄습니다.
- CSV 안전성: UTF-8 BOM, 한글 7열, 데이터 0행, 수식 셀 0개를 확인했습니다. 내려받기 전에는 고객 값을 받지 않습니다.
- 무저장 주장: 날짜와 체크 상태는 React 메모리에만 있고 storage와 fetch를 호출하지 않습니다. 사용 이벤트는 고정 enum만 보냅니다.
- 유입 위조와 개인정보: 명시 UTM은 안전 문자 60자로 제한하고, referrer는 exact 또는 dot-boundary hostname만 판별합니다. 전체 주소, 경로, 검색어는 반환하거나 저장하지 않습니다.
- 퍼널 수학: 기존 중첩 퍼널 정의를 유지하며 검색, AI, 직접, 기타 네 채널에 같은 도달 조건을 적용합니다. 기존 `utm_sources` 응답은 유지합니다.
- 접근성: 한 페이지 한 개 H1, 입력 label, 결과 live region, 오류 alert, 체크리스트 fieldset, 키보드 링크와 버튼을 유지합니다.
- 검색 품질: 세 공개 URL에 canonical, index/follow, WebPage와 Breadcrumb 구조화 데이터, 사이트맵, 랜딩·FAQ·블로그의 직접 링크를 제공합니다.

## 유지한 결정

- 알 수 없는 명시 UTM source는 차단하지 않고 `other`로 묶습니다. 기존 캠페인을 잃지 않으면서 관리자 채널 표에는 안전한 고정 그룹만 노출하기 위한 결정입니다.
- 로그인하지 않은 외부 AI의 접근 제한 결과는 인파 미언급으로 계산하지 않습니다. 실제 답변을 받은 네 건만 기준선에 반영했습니다.

검토 종료 상태: Critical 0, Important 0. 위 네 발견은 모두 수정하고 회귀 테스트를 추가했습니다.
